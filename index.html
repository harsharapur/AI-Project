Enhancing Object Removal in Images Using Text Prompts

Harsha Rapuru, Hareen Sai Vattikuti

Motivation and Problem Statement

Motivation

Image editing often involves removing unwanted objects like people, animals, watermarks, or timestamps. Traditional methods rely on manual masking, which is tedious and time-consuming — especially for scenes with multiple or complex objects.

As AI evolves, there's growing demand for intuitive, natural-language tools that can simplify editing tasks through simple commands like “remove people from background.”

Problem Statement

Current image editing tools require users to create detailed masks manually. This process is inefficient and inaccessible for non-experts. Some automated tools exist, but they often lack natural language interfaces.

Related Work

We explored InstructPix2Pix which enables editing using prompts like:

  • Remove people
  • Remove dog
  • Remove car

Source: https://huggingface.co/spaces/timbrooks/instruct-pix2pix

Datasets

  • Grounding DINO: Trained on LAION-400M and OpenImages.
  • SAM: Trained on SA-1B dataset (11M+ images, 1B masks).
  • Stable Diffusion: Trained on LAION-5B.
  • Custom Dataset: 1000 training and 100 testing images from Google Street View (urban clutter).

Quantitative Metrics

  • SSIM: Measures structural similarity. Higher is better.
  • IoU: Evaluates object mask overlap. Higher is better.
  • LPIPS: Assesses perceptual difference. Lower is better.

Limitations

  • Hard to reconstruct complex textures and lighting
  • Artifacts when dealing with reflections or occlusions
  • Long processing time for high-resolution images

Conclusion

We developed a robust system that automates object removal using natural language. By combining Grounded SAM, Stable Diffusion, and LoRA, we simplified the editing workflow while improving realism and accuracy.

Future Work

  • Improved multi-object removal
  • Better handling of occlusions and poor lighting
  • Extension to video-based object removal
